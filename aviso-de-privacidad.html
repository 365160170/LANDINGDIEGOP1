1. Quién es responsable de tus datos

2. Qué datos se recaban

  • Datos de compra. Cuando compras el producto, el pago lo procesa Hotmart. Hotmart nos comparte tu nombre y tu correo electrónico para poder darte el acceso. Nunca recibimos ni almacenamos los datos de tu tarjeta o cuenta bancaria.
  • Datos de navegación. Si están activas las herramientas de medición, se recaban datos técnicos y de uso: páginas vistas, país aproximado, tipo de dispositivo y navegador, y origen de la visita.
  • Datos que escribes en la calculadora. Los montos que capturas en esta página se procesan únicamente en tu navegador para mostrarte el resultado. No se envían a ningún servidor ni se guardan.

3. Datos que se quedan en tu dispositivo

El presupuesto que armas dentro de la aplicación se guarda en el almacenamiento local de tu propio navegador. Eso significa que:

  • No tenemos acceso a esa información.
  • Si borras los datos del navegador, cambias de dispositivo o usas una ventana privada, ese presupuesto se pierde.
  • Por eso conviene descargar el PDF del plan como respaldo.

La aplicación no te pide contraseñas bancarias, números de tarjeta, CLABE ni acceso a tus cuentas.

4. Para qué se usan tus datos

Finalidades necesarias:

  • Entregarte el acceso al producto que compraste.
  • Darte soporte si escribes con un problema.
  • Atender solicitudes de reembolso, facturación y obligaciones legales.

Finalidades adicionales (puedes oponerte sin que afecte tu compra):

  • Enviarte avisos sobre mejoras o nuevas versiones del producto.
  • Medir de forma agregada cómo se usa la página para mejorarla.

Si no quieres que tus datos se usen para las finalidades adicionales, escríbenos a hola@TU_DOMINIO.com.

5. Con quién se comparten

No vendemos tus datos personales. Se comparten únicamente con los proveedores necesarios para que el servicio funcione:

  • Hotmart — procesa el pago y entrega el acceso. Tiene su propia política de privacidad y es responsable de los datos de pago.
  • Google — si está activo Google Tag Manager o Google Analytics, para medición de uso.
  • Meta — si está activo el Píxel de Meta, para medir la efectividad de la publicidad.
  • Proveedor de hosting — NOMBRE DEL PROVEEDOR, donde está alojada esta página.

También podríamos revelar datos cuando una autoridad competente lo requiera conforme a la ley.

6. Cookies y tecnologías similares

Esta página puede usar cookies y almacenamiento local para recordar tus preferencias y para medir el uso. Puedes bloquearlas o borrarlas desde la configuración de tu navegador; si lo haces, algunas funciones pueden dejar de recordar tus datos entre visitas.

7. Tus derechos (ARCO)

Tienes derecho a acceder a tus datos, rectificarlos si son inexactos, cancelarlos cuando consideres que no se requieren, y oponerte a usos específicos. También puedes revocar tu consentimiento o limitar el uso y divulgación de tus datos.

Para ejercerlos, escribe a hola@TU_DOMINIO.com indicando tu nombre, el correo con el que compraste y qué derecho quieres ejercer. Responderemos en un plazo máximo de 20 días hábiles.

Si consideras que tu derecho a la protección de datos fue vulnerado, puedes acudir ante la autoridad competente en materia de protección de datos personales de tu país.

8. Cuánto tiempo se conservan

Los datos de compra se conservan mientras dure la relación comercial y después durante el plazo que exijan las obligaciones fiscales y legales aplicables. Los datos de medición se conservan de forma agregada conforme a la configuración de cada herramienta.

9. Cambios a este aviso

Si este aviso cambia, publicaremos la versión actualizada en esta misma dirección y modificaremos la fecha de la parte superior. Te recomendamos revisarlo periódicamente.
